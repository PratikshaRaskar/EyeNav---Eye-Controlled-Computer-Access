# EyeNav — Eye-Controlled Computer Access

EyeNav is a webcam-based assistive technology project designed to make computer navigation more accessible for people who have difficulty using a traditional mouse or keyboard. It uses eye tracking, facial gestures, and voice-command capabilities to support hands-free interaction.

## Features

- **Eye Tracking:** Tracks facial and iris landmarks using MediaPipe.
- **Gaze-Based Cursor Control:** Moves the on-screen cursor based on eye and face position.
- **Calibration:** Helps personalize gaze tracking for the user.
- **Hands-Free Clicking:** Supports dwell-based clicking and configurable blink or wink gestures.
- **Voice Commands:** Includes voice interaction capabilities using web speech technology.
- **Accessibility Settings:** Offers configurable tracking sensitivity, responsiveness, cursor visibility, and other options.
- **Interactive Dashboard:** Displays tracking status, gesture information, and activity metrics.

## Getting Started

### Prerequisites

- Node.js and npm
- A webcam
- A modern browser such as Google Chrome or Microsoft Edge

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/PratikshaRaskar/EyeNav---Eye-Controlled-Computer-Access.git
   ```

2. Open the project folder:

   ```bash
   cd EyeNav---Eye-Controlled-Computer-Access
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
